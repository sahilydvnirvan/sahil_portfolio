SAHIL YADAV NIRVAN — PORTFOLIO

WHAT'S IN THIS FOLDER
  index.html      the website
  images/         every image the site uses (keep this folder next to index.html)
  og-image.jpg    the preview image shown when the link is shared

PUBLISH ON NETLIFY (free)
1. Go to app.netlify.com/drop and drag this whole "sahil-portfolio" folder onto the page.
2. Sign up / log in so the site stays online.
3. Site configuration > Change site name, e.g. "sahilyadavnirvan" -> sahilyadavnirvan.netlify.app

AFTER IT'S LIVE (link previews)
In index.html, near the top, replace YOUR-SITE with your Netlify name in the three
commented lines (canonical, og:image, og:url) and remove the <!-- --> around them.
Then drag the folder onto your site's Deploys page again.

UPDATING LATER
Change the files, then drag the whole folder onto the Deploys page. The link stays the same.
